# Legacy アカウント連携と NavMate 移行

Cloudflare Access 保護下の Legacy アカウントを Firebase Google アカウントへ 1 対 1 で連携し、「未連携 → 連携済み → 移行中 → 移行完了（NavMate 有効）」の状態機械で Project と直前正常計算結果を一括移行する契約の正本です（#186）。旧サーバー廃止・救済手順は [server_retirement.md](server_retirement.md) を参照してください。

## 権限・所有権と状態機械

- **1 対 1 連携の厳格な本人確認**：サーバー永続台帳上で Legacy 所有者と Google アカウントを一意に紐付けます。連携を作成できるのは **署名済み Cloudflare Access 所有者かつ検証済みの有効な Google 本人** の組み合わせのみです。メールアドレス一致、クライアント申告の ID、開発用ローカル固定識別子、再紐付け、所有者統合は禁止します。連携作成時点では Project データを読み書きしません（トークンはリクエスト検証のみに使用し永続化しません）。
- **起動時有効化ゲート**：NavMate はアカウントの作業環境を作成する前に有効化状態を確認します。連携済みの場合は追加確認なしで自動的に一括移行（進捗表示あり）を開始し、有効化確認完了まで匿名データ取込や既存アカウント同期を実行しません（アカウント内の別 Project には触れません）。
- **所有者ロック**：Legacy の通常操作（実行中の計算とその完了保存を含む）と移行処理は所有者単位でロックを共有します。すでに実行中の計算は完了まで待ち、その後に来た操作は安全側で拒否します（他所有者の利用は継続可能）。Legacy サーバーは単一プロセス構成を維持し、同一データディレクトリを共有する複数ワーカーを構成しません。

## 移行データ・冪等リトライ・非可逆性

- **移行対象**：可視な保存済みチェックポイント＋現在下書き、および所有者の自動保存専用 `Latest` を対象とし、各データの所有者一致を確認したうえで Legacy 固有所有者情報を除去し、整合性と計算入力の一致を検証して移行します（古い計算結果は除外し、破損レコードがあれば有効化を停止）。UI セッション、Cookie、Access 資格情報、気象キャッシュ、未確定取込候補は移行しません。元の Legacy ファイルは #146 救済判断のため保持します。
- **大容量対応と一括確定**：利用者本人の認証資格情報を用いて 1 コミットあたり上限（最大 25 件／約 6 MiB）内のバッチで移行し、1 件あたり 1 MiB 制限に対しては [大容量 Project の可逆圧縮](account_sync.md#large-project-payloads) を使用します（圧縮後も上限に収まらない場合は欠落させず失敗）。最後に一貫した読み取りで全対象を検証してから移行完了を確定します。
- **レシートによる冪等再試行**：リモート書込の直前に「書込予定レシート」を永続化し、応答喪失時でも内容・バージョン一致で判別して再試行します。
  - 同一 ID・同一内容なら再書込せず採用。
  - レシートと一致するリモート値は新しい Legacy 値へ前進更新可能。
  - リモート側で独立に編集・削除された値や別端末の `Latest` は上書きしない（移行側 `Latest` には移行専用の端末識別を与え、既存 NavMate 端末の `Latest` を上書きしない）。
- **障害回復とロック解放**：移行・保存・通信エラー検出時は状態を「連携済み」へ戻します。ブラウザ強制終了や通信断で移行ロックが残った場合も、**180 秒の非活動リース** 経過後に次回状態確認／操作で安全に解放されます（未認証リクエストによる他アカウントのロック解放は不可）。完了済みバッチは維持され、次回ログイン／リトライ時に新しい Project ID を重複発行せず再開します。
- **移行完了の非可逆性**：通常操作からの巻き戻しはできません。移行完了後は Legacy へのアクセス時に自動的に NavMate へ転送され、旧編集操作も拒否します（NavMate 側の変更を Legacy へ書き戻しません）。一度有効化を確認した端末は完了状態を記憶して以後のオフライン利用で Legacy に依存しませんが、新規端末や未連携状態だった端末は移行期間中、起動時に有効化状態を確認します（移行サービス到達不可時は未連携キャッシュを作らず再試行／ログアウト画面で停止）。

> **参考（環境設定・Access Bypass 境界・検証手順）**：Legacy Compose と NavMate の環境変数、Cloudflare Access Bypass（`/api/navmate-migration/*` 限定）のセキュリティ要件、展開順序、およびエミュレータ検証コマンドは [firebase_account_operations.md](firebase_account_operations.md#configure-the-migration-period) を参照してください。
