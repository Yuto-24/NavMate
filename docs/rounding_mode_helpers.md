# 四捨五入モード

NAV LOG の計算結果に対する「通常／四捨五入」切替（#234）の数値規則、表示投影、および一時設定のライフサイクルを定めます。仕様全体の正本は [計算規則](calculation_rules.md#四捨五入モード) です。

## 概要と UI 配置

- 計算後の NAV LOG サマリー直下（VOR/DME 列追加と同じ行の右側）で「通常／四捨五入」を切り替えます。切替時には再計算を行います。
- 互換維持のため、初期値は **OFF（通常）** を暫定既定とします。
- UI 配置は 390 / 1100 / 1440 px のブラウザレイアウト検討において、目的地風の右側配置案では 1100 px で風の説明が折り返してサマリー高さが増える（65 px → 81 px）のを避けるため、VOR/DME 行の右側を採用しています。

## 数値規則と計算・表示への適用

### 風向の丸めと計算入力

- **ON 時**: 気象モデル（FORECAST / FTD）の補間後、および手入力の採用後に、共通採用風向を `[0, 360)` の範囲へ正規化し、**10° 単位の half-up**（中間値は 0 から遠ざかる方向へ丸め、`360` は `0` へ戻す）へ丸めて航法計算（上昇・巡航・降下の風力三角形）と表示に使用します。
  - 例：`5° → 10°`、`355° → 0°`、入力 `-5° → 0°`。北の文字列表記（`000` / `360`）はこの丸め規則の対象外です。
- **OFF 時**: 有限な入力値をそのまま使用します。
- 欠測値は欠測のまま維持し、無限大や非数値などの不正値は入力エラーとして扱い、0 へ補完しません。
- 風速および CALM 判定は変更しません。欠測風向を使用できるかは既存の風力三角形の契約に従います。
- MH や GS そのものを 10 刻みに丸めることはしません。また、VREP 以降の航法 CALM 固定および目的地 TAF の独立表示は維持します。

### 表示投影（DME・TOAT）と half-up 規則

- **DME**: ON 時のみ、VOR/DME 列の距離を **0.5 NM 単位の half-up** で表示投影します（例：`1.25 → 1.5`）。OFF 時は従来の 0.1 NM 表示を維持します。測地計算の内部距離および radial は変更しません。
- **TOAT**: ON 時のみ、各行の TOAT 表示値を **1℃ 単位の half-up** で表示投影します（負のゼロ `-0.0` は正の `0` へ揃えます）。OFF 時は 0.1℃ 刻みを維持します。地上気温・採用気温の実効値、継承／欠測状態、性能計算用の内部気温は変更しません。
- **half-up 規則**: 正の丸め単位に対して中間値は常にゼロから遠ざかる方向へ丸めます（`-1.5 → -2`、`-0.5 → -1` であり、ties-to-even や負方向の切り捨てではありません）。
- 手入力の風向・気温は元の入力値を保持し、ON 時の非編集表示では採用表示値を示し、フォーカス中の編集では元の値を編集できます。
- 表示済み MC と WCA から MH を算出する算術、子表示値からの距離・時間・燃料集計、EOC 継承条件は従来どおり維持します。

## 一時設定のライフサイクルと失敗時の振る舞い

- 四捨五入モードは**同じ作業中のセッション内のみ**保持し、新規作業、Project の読込、またはページの再読み込みでは **OFF へ戻ります**。恒久的な設定保存方式は引き続き未確定であり、Project の保存内容には含めません。
- ON の状態で完了した計算結果を保存・復元した場合でも、その計算条件を次回の設定へ自動引き継ぎはしません。復元時は保存データを保持したまま、画面上は未計算扱いとして OFF での再計算を求めます。
- 同じ作業内の通常保存、失敗した Project 読込の巻き戻し、およびセッション再接続時には、現在のモードと対応する計算結果を一緒に引き継ぎます。
- 切替は処理中・未保存／不正な入力・自動再計算中の重複操作を抑止し、再計算に成功した場合のみモードと結果を同時に確定します（表示だけを先に切り替えません）。
- 例外だけでなく、丸めによって風力三角形が解けなくなる等のブロッカー結果になった場合も、切り替え前のモードと計算結果を保持します。既に ON の作業が別の編集で計算不能になった場合は、OFF への再計算を試せます。
- 端末保存の失敗時に計算自体が確定済みであれば、確定済みの作業状態（現在のモードを含む）は維持します。
