# 地形入力と被覆の検証

地形標高データ（国土地理院 DEM10B）および確認済み地形点 KML の入力検証・被覆判定に関する上流仕様です（#313）。この入力境界を利用するSEA算式、区間・領域、Projectへの評価結果保存、手動値と表示は[区間別SEA](sea.md)で定義します。地形入力は気象計算には使用しません。

## GSI DEM10B の仕様と制約

- **配信元・形式**：国土地理院の `dem_png/14/{x}/{y}.png`（XYZ Web Mercator、x は東向き、y は南向き、入力座標は経度・緯度）。TXT 版は 2024 年 10 月以降更新停止のため使用しません。
- **復号規則**：256×256 ピクセル、8 bit RGB PNG を 24 bit 符号付き cm 値として復号し m へ変換します。`(128, 0, 0)` は欠損値として扱い、0 m および負標高と区別します。
- **標高基準と精度限界**：日本の標高は原則 TP（東京湾平均海面）ですが、離島には独自の基準があります。タイル自体は画素ごとの基準・測量時点・改定年度を含まないため、全画素を特定年度の TP へ変換済みとは扱いません。原資料は約 10 m 格子を平滑化した値であり、人工構造物を含まず、全画素取得であっても実地形の絶対最高点や運航安全性を保証しません。
- **被覆限界**：主な整備対象は日本国内であり、国内でも水部・境界・未整備域に欠損や不確かな値があります。地域名や HTTP 200 応答だけで完全被覆と判定しません。

出典・現行仕様（2026-11-09 確認）：[地理院タイル一覧](https://cyberjapandata.gsi.go.jp/development/ichiran.html)、[PNG 標高タイル仕様](https://maps.gsi.go.jp/development/demtile.html)、[標高タイルの作成方法と制約](https://maps.gsi.go.jp/development/hyokochi.html)、[日本の測地系](https://www.gsi.go.jp/sokuchikijun/datum-main.html)、[基盤地図情報 FAQ](https://www.gsi.go.jp/kiban/faq.html)。

## Local-first 取得と利用境界

- ブラウザから国土地理院へ HTTPS で直接取得し、専用サーバー・Worker・気象配信への追加は行いません。
- 固定ホスト・z14・整数タイル座標に限定し、認証情報送出およびリダイレクトを禁止します。
- **エラー分類**：HTTP 404 は「未整備・欠損」、1 要求 **10 秒** または領域全体 **既定 60 秒** のタイムアウト・通信・その他 HTTP エラーは「未取得」、1 応答 **512 KiB** 超過や PNG 形式・寸法・RGB・チャンク CRC／終端不正・色補正メタデータ・透明色含有・ブラウザ機能非対応は「不正タイル（形式不正）」として未確定を維持します（拡縮や色変換は行いません）。
- **事前検証と取得時上限の区別**：
  - **事前検証（領域・タイル数上限）**：領域不正または外接矩形 **64 タイル**・頂点 **128 個** の上限超過は「入力無効」として扱い、取得を開始せず、小さく切り詰めて完全被覆にしません（広域の分割・集約は呼び出し側の責務）。
  - **取得中の上限（サイズ・タイムアウト）**：取得開始後の 1 応答 **512 KiB** 超過は「不正タイル」、1 要求 **10 秒**・領域全体 **既定 60 秒** のタイムアウトは「未取得」となり、領域結果は「不完全被覆」となります（「入力無効」とは区別し、有効に取得できた部分の値も保持しつつ完全扱いしません）。
- **メモリキャッシュ**：検証済み PNG を最大 **16 枚・24 時間** メモリ内保持します。タイルの永続キャッシュ、タイル自体のProject保存、オフライン再取得保証は行いません。SEAの集約結果・出典の保存は[区間別SEA](sea.md)を参照してください。再取得時は HTTP キャッシュを再検証し、メモリキャッシュ利用時は元の取得時刻を維持します。
- 各タイルには URL、取得時刻、SHA-256、出典、単位、水平・鉛直基準を付帯します（SHA-256 は取得内容の識別子であり、GSI 保証の版番号や完全性証明ではありません）。区間別の画素数やタイル一覧は画面に表示せず、[SEAの診断情報](sea.md#診断情報の保持と再利用)として保持します。

## 領域選択と被覆状態の契約

- 入力領域は「始点を末尾に重複させない、自己交差のない単一ポリゴン」とし、辺は Web Mercator 上の直線として扱います。穴あき、日付変更線越え、極域は未対応（入力無効）です。
- ポリゴン内部または境界と接する**画素の閉じた範囲**をすべて選択します（境界外側に中心がある画素も含む保守的な選択）。境界の欠損を除外したり、離散サンプルだけで完全性を主張したりしません。
- **被覆状態**：
  - **完全被覆**：選択された全画素に有効な標高がある（実地形の最高点は保証しない）。
  - **不完全被覆**：取得中に未整備・欠損、未取得（10 秒 / 既定 60 秒タイムアウトや通信エラー含む）、不正タイル（512 KiB 超過や PNG 不正含む）のいずれかを含んだ状態。有効な部分の値も保持するが、部分最大値を確定 SEA にしたり完全被覆とみなしたりしない。
  - **入力無効**：事前検証で領域不正または 64 タイル・128 頂点の上限超過と判定された状態（取得未実施）。
- 必要／有効／欠損／未取得／不正の各画素数を区別して保持し、例外や失敗時にも既存の Route やローカル保存を変更しません。

## 地形点 KML の入力と障害物除外

Route 用 Import とは独立した素の KML の入力境界であり、Point 高度だけから地表・飛行高度・障害物頂部を推定しません。
画面からの地形点KMLの取込・解除と、出典・標高基準の確認欄は廃止しました。
以下は既存Projectの地形点を引き続き扱うために維持する契約であり、通常の利用者に新たな資料入力を求めるものではありません。
保存済みの点と確認根拠は保持し、経路用KMLのImportとは分離します。

### 採用条件と標高基準

利用側（資料を確認した呼び出し元）が以下の 4 条件をすべて明示的に確認・指定した場合にのみ、有効な地形点として採用します（KML 内の自己申告やファイル名から自動生成せず、文字列の存在だけで出典真偽を認証するものでもありません）。

| 確認項目 | 採用条件 |
| --- | --- |
| 資料識別 | 作成元・資料の識別子が明確であること |
| 点の意味 | 当該ファイルの点が「地表標高」であると確認済みであること |
| 標高基準 | 実際に格納された数値の標高基準が TP（東京湾平均海面）であること |
| DEM 整合根拠 | 全点の地域・標高基準・測量/改定時点を、使用する DEM と照合した根拠があること |

- 通常の KML は経緯度が WGS84、absolute 高度が EGM96 基準の m であるため（[OGC KML 仕様](https://docs.ogc.org/is/12-007r2/12-007r2.html)）、「`absolute`」「`MSL`」の記載だけでは TP との同一性を認めません。ジオイド変換や離島独自基準・異なる成果年度の一律合算は行わず、基準不明・未確認は「基準未確認」として値を採用しません。

### 受理形式・上限・結果状態

- **対応形式**：KML 2.2 namespace（OGC / 旧 Google）の 1 Placemark に 1 Point。`longitude,latitude,elevation` の有限数値 3 項と明示的な `altitudeMode=absolute` が必須です（高度省略を 0 m にしません）。相対高度、clamp、gx 高度モード、説明 HTML 内の Height/Elevation、線・面・MultiGeometry からの補間面生成は非対応です。
- **安全・容量上限**：KMZ は対象外。**2 MiB・10,000 Placemark** まで（超過時は部分取込せず拒否）。DTD / entity・`NetworkLink` は拒否し、外部参照へアクセスしません。
- **結果の分類**：
  - **入力なし**：KML が渡されていない状態
  - **採用可能／一部採用**：有効な地形点がある状態（一部採用時は不採用点の理由を保持）
  - **空**：Placemark が 0 件
  - **形式不正**：XML・形式・数値・容量上限の不正により採用点が 0 件
  - **基準未確認**：地形点の意味・出典・標高基準・DEM 整合の確認不足
  - **障害物除外**：障害物資料として除外された入力
- 数値の `0 m` と負標高は有効とし、不採用値を 0 補完しません。範囲外の点は最高値候補にせず、KML の被覆は常に「点のみ（周囲や未取得 DEM 領域を補完しない）」として扱います。

### 障害物 KML（AREA1）の除外方針

`AREA1_45_MIYAZAKI_20261029.kml` のような風車・鉄塔等の障害物 Point 資料は、説明欄に `Height` / `Elevation` / `OTHER:TP` の記載があっても座標第 3 値や `altitudeMode` の要件を満たさない障害物データであるため、2026-11-09 のユーザー確認に基づき **障害物として除外** し、説明欄の数値を地表標高へ転用しません（提供ファイル本体はリポジトリに同梱しません）。
