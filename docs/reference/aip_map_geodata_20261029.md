# AIP地図表示用データ（2026-10-29有効）の出典・正規化

## 確認済み事項

2026-10-22付の航空情報センター配布「AIPに関する地図表示用データ」のKML・Shapefile（各25レイヤー）を確認した。適用日は**2026-10-29**。Shapefileは全5,276地物で、CRSはWGS84（EPSG:4326）、全レイヤーのgeometryは空・不正ともに0件。元ファイルのSHA-256とレイヤー別件数を[`source_manifest.json`](../../data/reference/aip/20261029/source_manifest.json)に記録する。

出典：国土交通省航空局 航空情報センター、[SWIM portal](https://top.swim.mlit.go.jp/swim/) → AIPファイルダウンロードサービス → `3_AIP(KML, Shapefile)`。配布ファイルを検査して本記録を作成した。原本と加工データを混同せず、[SWIM利用規約](https://top.swim.mlit.go.jp/swim/terms.html)に従い出典と加工の有無を表示する。第三者の権利および個別の提供条件も必要に応じて確認する。

KMLは全5,271 Placemarkで、Shapefileと件数が異なる。`Approach_control_area_CIVIL`はKML 93件／Shapefile 94件、`Approach_control_area_MIL`は75件／79件で、他の23レイヤーの件数は一致する。以下の表とmanifestの`layers[].feature_count`はShapefileを基準とする。形式間の差分は下記の照合結果で説明する。原本ZIPは変更しない。

## 表示仕様（利用者決定）

- 経路の新規作成中、再編集中、確定後のPlanning画面で、訓練空域と公示空域を同じMAPへ表示する。
- 操作ペインの「経路」セクションの下に、初期状態では折りたたんだ「空域表示」を置き、経路確定後もON/OFFの選択を保って自動で折りたたむ。AIPの16カテゴリを個別にON/OFFでき、地図内に同じ操作メニューを重複して置かない。選択欄には項目と読込状態だけを表示し、出典リンクは「その他 → 地図の出典」にまとめる。ラベルは文字選択できず、ラベルのクリックやキーボードで切り替えられる。
- 地図の境界線と選択ボックスはカテゴリごとに同じ色を使う。標準地図は濃色、衛星・空中写真は同じ色相の明色で表示し、AIPの境界線は写真背景で太くする。宮崎PCAの境界と中心除外円も選択ボックスと同色にし、中心除外円の破線は維持する。
- AIP表示設定がない端末では、民間訓練・試験空域、進入管制空域（民間）、飛行制限空域の3カテゴリだけを初期ONとし、他13カテゴリはOFFにする。全カテゴリONを含む既存の保存設定は、再読み込みやProject切替後も維持する。
- 宮崎特別管制区（PCA）は、既存の宮崎発着経路での表示条件を保ち、同じ「空域表示」から境界と中心除外円を一緒に切り替える。PCAの設定がない端末では初期ONとする。AIP・PCAの表示設定は端末内にのみ保存し、Project・Account Sync・Last Calculation・計算入力の同一性判定を変えない。
- エリアのクリック・Hoverから詳細表示やRouteへの追加は行わない。MAP上の地点追加・編集操作を妨げない。
- 配布データは共有MAP Reference Dataであり、#176の経路KML Importや個人Overlayとは別責務。

## 既存境界と更新時の注意

国土地理院のライブ KS4 表示データ、および RJFM 帰路案内用の AIP 由来 KS4-3 計算用境界が先行実装として存在します。公式 AIP の新たな MAP レイヤーを登録しても、**計算用境界、境界誤差、計算入力の同一性判定、可用性判定を自動で置き換えない**。差分照合を経て、用途ごとの責務を維持すること。

初期版の配布は既存方針に従い、version付きStatic Web artifactとしてApp releaseに同梱する。AIRACごとの有効日管理、出典・更新履歴、検証を行い、**有効日を理由にMAP表示を禁止しない**。有効日は出典・更新管理のメタデータとして保持し、実際の運航で適用する情報の確認とは区別する。

## 共通参照データの契約（#311）

登録済み25レイヤー・5,276地物を、Shapefileの地物単位を保った2次元GeoJSONとして配布する。
空港・航路・位置通報点も元のレイヤー区分を保持し、すべてを空域ポリゴンとは扱わない。
ポリゴンの穴・複数部分を保持し、簡略化・形状修復・高度帯ごとの複製は行わない。
原本にZ/M座標がある場合は、元のXY座標・部分境界・Z/M配列を別属性として保持する。
Mの欠損は欠損のまま残し、Z/Mを空域の高度制限とは解釈しない。

各地物は元属性、出典内の位置、元属性から採ったラベル、上限・下限を持つ。
ラベルとなる属性がない地物はラベルなしとし、新しい空域名は作らない。
データセットには発行元、原本の検証値、AIRAC有効日、加工履歴、正規化結果の検証値を保持する。

| 高度の原表記 | 正規化後の意味 |
| --- | --- |
| `FL150` | 値150、単位FL、標準気圧基準 |
| `1700FT AGL` | 値1700、単位FT、地表面基準 |
| `6000FT` | 値6000、単位FT、基準は未指定。MSLを推測で補わない |
| `SFC` / `GND` | 表面。原表記を保持し、標高0へ置換しない |
| `UNL` | 上限なし。数値へ置換しない |
| 空欄・属性なし | 欠損。SFCへ置換しない |
| `-`、時刻・NOTAM条件などの複合表記 | 解釈未確定。原文を保持する |

高度の注記、境界を含むか除くか、複数高度帯やNOTAM依存の条件は元属性として残す。
数値化できた上下限だけで空域全体の使用可能高度を判定しない。
TCA未提供、ACA対応未確認、NOTAM・現行activation未対応の状態を配布データにも明記する。

正規化は登録済み原本から再現でき、原本の改変、空・不正geometry、同一レイヤー内の
geometryと属性がともに同じ重複、レイヤー・件数の欠落があれば配布用生成を失敗させる。
同じ水平形状でも高度属性が違う地物は別地物として保持する。
アプリと同じrelease単位で配布し、参照データの版数・検証値・必要ファイルの欠落を検査する。
計算用データと分離するため、この表示用データの追加でRJFMのKS4-3境界や計算fingerprintは変わらない。

## 形式間照合（EFF20261029原本、2026-11-21確認）

全25レイヤーで原本の件数とgeometryを検証し、件数差がある進入管制空域2レイヤーは
地物・属性を照合した。残る23レイヤーは件数一致を確認した範囲であり、全属性の同一性を意味しない。
ShapefileとKMLは交換可能な同一データとはみなさず、正規化の採用元はShapefileとする。

| レイヤー | 件数差の理由と扱い |
| --- | --- |
| 民間進入管制空域（94対93） | ShapefileのHiroshima 1地物とKansai 2地物に対し、KMLはKansai,Hiroshimaの2地物に高度別の管制主体を記す。Kansaiの水平形状は一致するが、その2地物の和集合とHiroshimaの形状は完全一致しない |
| 軍用進入管制空域（79対75） | Iwakuni 3組とTsuiki 1組は、Shapefileの同一水平形状・異なる高度属性の各2地物をKMLの各1地物と除外高度注記で表す。これが4件差となる |
| 軍用進入管制空域の追加差 | Chitose 2地物はKMLでSapporo,Chitoseと高度別の管制主体を記す。Sapporo 2地物には水平形状差もあり、関連KML形状の和集合でも完全一致しない |

KMLには高度範囲の途中を除外する注記があり、Shapefileには上下限が同値の地物もある。
いずれも欠損や誤りと決めつけず原属性を保持する。配布物の照合記録には、該当地物の出典内位置、
両形式の元属性、水平形状の一致判定・差分を残す。境界の選択や航空上の意味を推測して統合しない。
