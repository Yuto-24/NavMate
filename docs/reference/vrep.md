# 登録 VREP カタログと地図選択仕様

VREP カタログの出典と、MAP 上での選択・表示・保存済み経路の更新ルールを定めます。

## 対象範囲と公表座標

- [AIP地図参照データ](aip_map_geodata_20261029.md)の Visual_REP（有効日 2026-10-29）に収録された **528地点の公表WGS84座標**を採用します。ARPからの真方位・距離で位置を再計算せず、これらは出典属性として保持します。
- 長崎・大村の共用10地点は、原本どおり共用の地点として扱い、二重登録しません。
- 選択した地点には、座標・名称・出典・有効日を保存します。有効日は出典の版を示すもので、現在の運用状況やNOTAMの反映を保証しません。
- 旧115地点の導出方法と原典は、[承認済み原典表](vrep-169-confirmed-source.md)に履歴として残します。

## MAP 上の選択・表示・永続化

- 候補レイヤーは経路作成（および再編集）時にのみ表示します。未選択の空港と VREP は共通の **40 画面ピクセル単位クラスタリング** を用い、クラスタをクリックすると地点追加せずズームします。
- **承認済みシンボル**：VREP は外枠込み **20 px の二重円**（内輪 10 px、選択時はティール `#0c7c78`、白抜きの内マーク）、空港は **2 px 枠線込み 28 px の飛行機円**（選択時はネイビー、白抜きの内マーク）、いずれも 28 px のクリック領域中心に配置します。未選択シンボルは白色です（識別性および航法施設記号との誤認防止のため、四角＋ダイヤや幅広テキストバッジは不採用）。
- 選択済みの参照点はクラスタリング対象から外して個別描画し、再クリックすると同じ点の新たな出現を経路へ追加します。背景地図の何もない場所をクリックした場合は、スナップしない任意 Waypoint を追加します。
- 空の経路は空港からしか開始できず、経路確定には始点・終点ともに空港が必要です。
- 経路内の各地点（連続する重複選択を含む）は個別の地点識別子で管理しつつ、参照点としての共通識別子および選択時の出典情報（座標・方位・距離・公表データの版）を地点ごとにスナップショット保存します。
- 作業中セッションやMAP下書きの復元では保存スナップショットを維持します。保存済みProjectを選んで開く場合は、次節の条件で旧導出地点を更新します。
- 到着計画における最終 VREP としての役割は引き続き到着直前の最終点のみを指します。経路途中に選んだ登録 VREP は参照点スナップショットとして区別され、到着計算の特別な意味は持ちません。
- 連続した同一地点の選択自体は保持されますが、ゼロ距離 Leg が計算可能であることは保証せず、既存の経路・Readiness 検査がそのまま適用されます。

## 保存済みProjectを開いたときの更新

Static / Localで保存済みProjectを選んで開くと、保存版と下書きにある旧115地点の座標・出典を公表データへ更新します。旧スナップショットの内容と、経路地点の座標・参照元が一致し、新旧の対応が確認できる地点だけが対象です。手動で変更した座標、出典が異なる地点、対応不明の地点は、自動変換の対象にしません。

保存版とは別に手動編集した下書きがある場合、破棄を承認して通常どおり開くと、更新後の保存版が下書き全体を置き換えます。下書きを復元して開く場合は、その手動編集を維持します。

地点ID・経路順・利用者が付けた名前・計画入力は維持します。前回の計算記録は書き換えず、座標が更新された経路は再計算が必要です。

一覧表示や作業中セッションの復元だけでは更新しません。更新済み地点には同じ変換を繰り返しません。開く操作の取消し、保存競合、書込み失敗があれば元記録と直前の作業を保持します。Legacyから移行したProjectも、Static / Localで開いたときに同じ条件で更新します。

## 初期展開の履歴と参照

- #169 初回反映時（2026-10-26）は新規 MAP 経路のみが対象でしたが、その後に確定済み経路の再編集（#175）と 1 画面統合（#416）が統合済みです。最新の MAP 操作仕様は [MAP での経路作成・再編集・KML/KMZ 取込](../map_route_builder.md) を参照してください。
- 登録地点の元資料・座標導出の記録は [承認済み原典表（vrep-169-confirmed-source.md）](vrep-169-confirmed-source.md) を参照してください。
