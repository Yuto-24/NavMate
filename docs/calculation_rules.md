# 計算規則

この文書は、NavMateが実際に採用する計算・表示Policyの正本です。

一部のPolicyは航空大学校の内部運用資料を参照して設計・検証していますが、このRepositoryでは原資料の章節、ページ、原文要約、hashとの対応を保持しません。公開範囲の考え方は[出典・provenance方針](source_policy.md)を参照してください。

SR22性能値については、Cirrus Design SR22 AFM/POH P/N 13772-006 Revision A1を参照します。性能頁5-30〜5-34はLOEP上Reissue Aです。

## NAV LOGの基本Policy

- 内部計算は原則として未丸め値を保持します。
- 表示時は方位1°、距離0.5 NM、時間0.5分、燃料0.1 galへ丸めます。
- WGS84測地線でLegの距離と初期真方位を求めます。
- NAV LOG計算では計画MSL高度をPAとして扱い、QNHによるPressure Altitude補正は行いません。
- 通常のVARは各Physical Legの出発点緯度から自動選択します。32.0°N以上は8°W（加算値+8°）、32.0°N未満は7°W（加算値+7°）です。
- 西偏差を正として`MC = TC + VAR`、右WCAを正として`MH = MC + WCA`とします。
- VOR Tracking Modeの第1 Physical Legだけは出発VORの公示DeclinationをVARに使います。RCA・C'k Point・EOCで分割されても同じ偏差と元LegのWGS84初期TCを使い、`MC = TC + VAR`、`MH = MC + WCA`を維持します。WCAはTCと風だけから求めます。第2 Leg以降・Mode OFF・到着処理は従来の緯度別偏差です。
- 第1 LegのMC/MHは出発VORの磁気基準です。現地の磁気方位計との一致は保証しません。経路上の各点へのVOR Radialは同じ出発点からのWGS84初期方位なので、途中の局所接線方位の変化をMCへ加えません。VOR/DME列の選局はこの基準を変更しません。
- 保存済みデータの互換性は維持しつつ、MCに加える磁気偏差の符号は常に西正とします。
- NAV LOGへ表示するMHは、同じ行に表示する丸め済みMCとWCAから作り、画面上の算術を一致させます。
- VFR巡航高度候補の方向判定は、NAV LOGへ表示する1°単位のMCを使用します。359.5°以上は表示360°、判定上は0°側とします。

## 四捨五入モード

計算後のNAV LOG上部で切り替え、切替時には再計算します。互換維持の暫定既定はOFFです。
ON時は共通採用風向を10° half-upへ丸めて航法計算と表示に使用し、MH・GS自身は10刻みにしません。
DMEは0.5 NM、TOATは1℃の表示投影だけを行い、内部距離・気温を保持します。
OFFの従来表示・計算は維持します。モードは同じ作業中のみ保持し、新規作業・Project読込・再読込でOFFへ戻します。
境界値・失敗時の扱いと保存設定の未確定範囲は[四捨五入モード](rounding_mode_helpers.md)を参照してください。

## Phaseと代表気象

Flight Phaseは`CLIMB`、`CRUISE`、`DESCENT`、`VISUAL_ARRIVAL`を扱います。

- CLIMBの代表気象高度は、出発空港標高と巡航高度の中間です。
- CRUISEは巡航高度です。
- DESCENTは巡航高度とVREP高度の中間です。
- 目的空港情報行の地上気温は空港位置・空港標高に対応する地上気温を使用します。
- FORECASTでは同じForecast Runを固定し、代表時刻が収束するまで最大5回反復します。代表時刻差30秒未満を収束とします。
- FTDでは地上風と5,000 ft風を東西・南北成分へ変換し、0〜5,000 ftを線形補間します。5,000 ft以上は5,000 ft風、気温はISAを使用します。

## CLIMB

- 自動TASはCAS 111 ktとCLIMB代表高度の気温から算出します。
- 上昇ETE、燃料、参照距離はSR22上昇性能表を使用します。
- 現行データはPOH原表の高度節点を500 ft刻みへ線形補間したISA基準行を収録します。
- 標準より高温の場合は、中間気圧高度のISA温度との差に応じて1℃あたり1%を加えます。標準以下では減算しません。
- 高度軸だけ、表端から500 ft以内の外挿を許可します。
- RCAは上昇ETEを経路始点から前向きに消費して配置します。経路が途中で変針する場合、Legごとの風力三角形を使用します。

## CRUISE

- 宮崎NAV2の標準Cruiseは65% Best Powerです。
- SR22巡航表の各PA / ISA cornerで65% PWRを先に解決し、その後ISA偏差、高度の順で区分線形補間します。
- 65%を挟むPWR行があるcornerではPWR軸を線形補間します。
- 掲載PWR範囲外では、最寄り2行から65%へPWR軸を線形外挿します。
- 高度・ISA偏差方向の外挿は行わず、範囲外では表端条件を採用し確認事項を残します。
- KTAS/GPHは補間後に0.1単位のties-to-evenで確定します。
- ノーズフェアリングありではPOH KTASを使用し、なしでは-10 KTASとします。A/C ON時はさらに-2 KTASです。GPHは補正しません。
- 手入力TASは最終採用値として扱い、上記のKTAS補正を重ねません。

## DESCENT / EOC

- 降下率は500 fpmを標準とし、利用者が1000 fpmを選択できます。
- 自動DESCENTではEOC直前の実効CRUISE Calculation ZoneのCASを共通CASとして使用します。
- EOC以降のDESCENT燃料は12 GPHです。
- EOCは降下に必要な時間をVREPから逆算して経路上へ配置します。まずDESCENT基準Leg自身の計画高度から候補を求め、前Legへの遡りが不要なら従来どおりそのLeg内で確定します。
- **高度連続性**：候補EOCまでの通常高度変更を、実効CRUISEの所要時間と上昇900 fpm／降下500 fpmで追跡します。短いLegで高度変更が終わらない場合は、その到達高度を次のLegへ引き継ぎます。DESCENT基準LegからVREPまでの時間だけが足りても、EOC時点の高度が降下開始高度へ連続しない候補は採用しません。
- 前段の高度変更が未完了なら、必要な時間とLegごとのGSを考慮してEOCを手前のLegへ遡らせ、EOC以降はVREPまで連続した降下として扱います。途中の変針点で降下高度を瞬時に切り替えたり、失われた時間を表示用の降下率変更で補ったりしません。前段の高度変更が完了し、現在Leg内にEOCを置ける場合は不要な遡りをしません。
- 高度条件を保って経路始点まで遡っても降下を成立させられない場合はBlockerとし、矛盾した計算結果を正常完了として保存しません。
- 前Legへ遡る際、そのLegの計画高度が次のLegより低ければBlockerにします。さらに手前から低い計画高度の区間を飛び越える扱いにはしません。
- EOCとPhysical Turn Pointの経路上距離差が0.5 NM未満なら、内部計算上もTurn Pointへsnapします。ちょうど0.5 NMではsnapしません。
- snap後も、選択降下率から求めた降下計画とlevel-off後の60秒は保持します。NAV LOGの各ZoneのETEはsnap後の距離とLeg別GSから求めるため、降下計画の時間との差が生じ得ます。これは四捨五入モードとは独立した規則です。
- 共通Vertical Profile／3D KMLでは、保存されたsnap前後の位置から生じた時間差と確認でき、差の絶対値が30秒以内の場合に限り、描画用の降下率を調整します。EOC高度からVREP高度までを連続して描き、最後の減速60秒を確保します。NAV LOGの選択降下率・GS・ETE・燃料は変更しません。高度不連続、snapの根拠がない時間不足、30秒を超える差、減速時間を確保できないケースは描画補正しません。描画不能を理由に正常なNAV LOGをBlockerへ変えません。
- EOC後のTOAT、風、WCA、MH、GSは継承境界として最初のDESCENT行へ明示します。TOATはそのCalculation ZoneのDESCENT phaseの実効値を使い、直前と同値でも省略しません。以後の通常区間は既存の継承表示を維持します。

## VISUAL ARRIVAL

- VREPから目的空港まではCAS 121 ktを使用します。
- 航法計算上の風はCALM固定で、WCA=0、GS=TASです。
- 目的地TAF風は独立した目的空港情報として表示しますが、この区間の航法計算には使用しません。
- VREP高度はNavMateのstandard distance ruleまたは利用者のmanual overrideで決定します。
- RJFMのARITA / SHIRAHAMAについては専用Policyを適用します。

## 燃料計画

NavMateの固定Fuel Plan Policyは次のとおりです。

- TAXI/RUN UP: 10分、1.5 gal。RUN UPなしの場合は0分、0 galです。
- CLIMB: POH上昇性能から算出します。
- CRUISE: 採用したCruise GPHとETEから算出します。
- DESCENT / VISUAL ARRIVAL: 12 GPHです。
- ADDITIONAL: 10分、2.8 galです。
- TGL: 1回につき7分、2.0 galです。
- RESERVE: 45分、12.4 galです。
- `BOF = CLIMB + CRUISE + DESCENT + TGL + ADDITIONAL`です。
- `MIN REQUIRED = TAXI/RUN UP + BOF + RESERVE`です。
- `EXTRA = TOTAL - MIN REQUIRED`です。
- EXTRA enduranceは16.5 GPHで換算します。

表示Fuel PlanはNAV LOGと同じ表示済み0.1 gal値から再構成し、画面上の加減算を成立させます。canonicalなFuelPlanは未丸め値を保持します。

## RJFM北行き専用Policy

RJFMから大分方面へ北上する一部経路では、NavMateのRJFM専用Policyを適用します。

- UMK / OMARUは名称ではなく参照座標と距離で識別します。
- 適用中はRJFM→UMKをCLIMB、UMK→OMARUをCRUISEとして扱い、目標高度を5,500 ft MSLに固定します。
- 経路にOMARUがない場合は、条件を満たす経路へOMARUを補います。
- RJFMの次がOMARUの経路では実UMKを自動挿入し、RJFM→UMKとUMK→OMARUを物理区間として計算します。明示UMKは名称・座標・手入力を保持し、重複させません。
- 生成UMKで分割する元Legの手入力距離は、2つの物理区間の測地線距離比で按分し、合計を保持します。元Legの手入力コースは分割区間には使わず、各区間の座標からTCを計算します。自動補完を解除し、元の隣接関係に戻った場合は元の距離・コースを復元します。
- NAV LOG主表ではRJFM→OMARUを1つの親Legとして表示し、UMK/RCAを内部境界として扱います。
- RJFM→UMK/RCAのETEと燃料は、同じ気温補正を適用したPOHの5,500 ft到達値を優先します。この専用区間では`DIST / GS = ETE`を要求しません。
- 利用者が取り込んだKMLに対応するUMK / OMARU座標がある場合は、その座標を同梱参照値より優先します。

### RWY別参考案内

RJFMのRWY09 / RWY27について、NAV LOG本体とは独立した参考経路を生成します。

- RWY09はMC 092°を1,000 ft MSLまで維持し、左45°でMC 047°へ変針します。
- RWY27はMC 272°を1.5 NM維持し、右45°でMC 317°へ変針します。
- 延長旋回はRWY09が左、RWY27が右です。
- 固定バンク20°を基本とし、必要時は20°を超えない最大地上旋回半径で再計算します。
- UMK位置残差、高度残差、接線角残差、宮崎特別管制区との関係を候補判定へ使用します。
- 参考案内はNAV LOGのDIST、ETE、Fuel、Readinessへ加算しません。
- 国土地理院から取得する民間訓練試験空域GeoJSONは表示専用で、NAV LOG計算やPCA判定へ使用しません。

## 表示モデル

- 計算結果は、重複しない計算区間（Calculation Zone）を距離・時間・燃料の唯一の集計元とします。
- 表示用投影は、Physical Leg サマリーと計算区間の内訳を分離して構成します。
- Physical Legの表示DISTは0.5 NM単位へ丸め、そのtickを子Zoneへ最大剰余法で配賦します。
- 親ETEは表示済み子ETEの合計、親SECT FUELは表示済み子Fuelの合計です。
- REM Fuelは表示TOTALから表示RUN UPを引いた値を起点に、表示SECTを順に減算します。
- セルの表示状態として、「計算値を継承しつつ表示を空欄にする状態」「継承しない意図的な空欄」「本来必要な値を取得・算出できなかった状態」の 3 つを区別します。
- NAV LOG Summaryは正規のPhysical Leg / Zone値から計算コア側で生成し、Web表示層で再集計しません。

### 30° CUT の参考秒数

NAV LOG右端の `30° CUT (sec)` は、最初の30° Bank旋回のロールアウト完了から、
15° Bankの復帰旋回のロールイン開始まで、バンク0°で直進する整数秒です。
両旋回とそれぞれのロール時間は含めません。正常な結果は丸め後が0秒でも `0` を表示します。Physical Leg親行の入口に
対応する値だけを表示し、最初のLeg、内訳・separator・目的地情報行には秒数を重複表示しません。

- 入口の前後の採用TCで左右を決めます。180°ちょうどは右旋回とします。
  前Leg末尾の採用MHから通常30° Bankで、次LegのMCに右なら+30°、左なら−30°のMHへ旋回します。
  このCUTのMHには追加の風向修正を行わず、計画MHへの復帰は15° Bankとします。
- Roll rateは6°/secです。両旋回とも水平からロールインし、水平までロールアウトします。
  小さい旋回では目標方位を超えないようピークBankを制限します。CUT角30°は変更しません。
- 次Leg先頭Zoneの採用TAS・風を一連の動作中の一定値として使います。
  `MC = TC + VAR` の既存規約で真方位へ変換し、局所平面の東・北移動を積分します。
  バンク変化中の旋回角は解析積分、移動は各ロール区間・定常旋回区間を0.1秒以下でSimpson積分します。
  2つの旋回の横方向変位を打ち消す直線維持時間を求め、風の移動も全時間に含めます。
- 合流点が次の実Leg内にあり、復帰後の対地速度が計画コース方向を向くことを確認します。
  直線維持時間が負になる、Legが短すぎる、風で合流できない、必要値が欠ける場合は `—` です。
  小さい変針角も計算対象ですが、固定30°では解がない場合があります。
- RCA/EOCなど同じSectionの内部境界は変針点にしません。複数Sectionを統合した親行も保持し、
  入口の合流は最初のSectionが終わるまでに完了する必要があります。統合内の各変針の秒数は重複表示しません。
- 30° CUT の秒数は表示専用の派生値としてのみ扱います。
  DIST・ETE・ETO・TTL TIME・燃料・Readiness・経路・RJFMの20° Bank案内は変更しません。
  保存済み Last Calculation は、保存された経路の区分・採用済み気象・TASからこの派生値だけを
  復元時に更新します。旧定義の総時間や値のない旧記録も対象です。新たな気象取得やNAV LOG全体の
  再計算は行わず、計算fingerprintと他の計画値を保持します。必要な保存値がない場合は `—` です。
  端末保存・同期用の記録ではCUT秒数を空にし、表示時に復元します。これにより0秒を受け付けない
  旧端末もProjectを読み込めます。旧端末では新しい秒数を誤表示せず `—` とし、更新後に復元します。

## 手入力と保存

- 手入力TAS、気温、風はeffective Flight Phase単位で扱います。
- 入力変更後は、現在の入力が保存済み計算時の入力と異なる場合に再計算を要求します。
- Projectには最新draftと、明示保存されたcheckpointを保持できます。
- 最後にBlockerなしで完了したCalculationはProjectごとに1件だけ保持します。

## 使用制限

- NavMateは公式規程、公式様式、運航承認を代替しません。
- SEA、DEM、地形・障害物は現行計算対象外です。
- 参照値、気象、航空情報、ATC指示は利用時に最新情報と照合してください。
- POH性能頁についても、対象機の製造番号、日本承認AFM/POH、Supplementへの適用性は別途確認が必要です。
