# Browser Platform 境界

ブラウザ固有のファイル入出力、クリップボード、3D KML エクスポート、外部リンク、接続状態ヒント、および永続化アクセスを分離・集約し、計算コアや業務ルールをブラウザ依存から切り離す境界契約です（#120）。

## 責務の分担

| 責務 | 担当 |
| --- | --- |
| ファイル読取、ダウンロード保存、クリップボード、外部リンク、接続状態ヒント | Browser Platform |
| ファイル選択ダイアログ・ドロップ操作・選択キャンセル | ファイル入力制御 |
| KML/KMZ 解析、アーカイブ上限、文書選択、経路候補抽出 | 共通 Python 取込処理 |
| 操作実行、作業状態、下書き確定、計算、エラーの意味付け | [Application 境界](application_contract.md) |
| 再読み込み限定の作業復元、確定済み入力の保持、復旧失敗方針 | [Session ライフサイクル](application_contract.md#frontend-application-session--lifecycle-119) |
| Project / `Latest` / チェックポイント / 改訂 / 直前正常計算 / 容量退避 | [Local Project 永続化契約](local_persistence.md) |
| ブラウザ保存領域へのアクセスとリポジトリ生成 | プラットフォーム永続化アクセス |
| お知らせ既読管理とインメモリ代替 | お知らせ機能 |

## ファイル取込と Importer 境界

- ファイル選択・ドラッグ＆ドロップのいずれでも、読取結果は「ファイル名・種別・内容バイト列」のみを渡し、OS のローカルファイルパスなどを計算・取込処理へ渡しません。
- ブラウザ側で明らかに過大な選択ファイルを読み取り前に拒否し、アーカイブ上限・展開後容量上限・XML 安全性・座標・点数上限の最終判定は共通の取込処理が担います。
- 圧縮 KMZ で複数 KML が含まれる場合は候補一覧を返して利用者に選択させます。選択キャンセル時は何もしません（再選択も可能で、読取失敗時も直前の候補・下書きを保持します）。

## 計算結果エクスポートとクリップボード

### Project のJSONファイル交換

Static Web / Localモードでは、操作ペインの「ファイルを選択」「Google Earth からペースト」の下段にある「JSONファイルから追加」から、新しい保存済みProjectを追加できます。経路作成画面でのみ表示され、経路確定後の飛行計画画面では表示されません。

書き出しは計算後にNAV LOG末尾の「JSON」ボタンからのダウンロードのみで行います。`navmate.project` version 1形式で現在の確定済みProject入力を出力します。再計算前の変更も対象です。

ダウンロード名は、JSONが出力時刻の日本時間（JST）を使った `プロジェクト名_yyyymmdd-hhmm.json`（飛行日付ではありません）、PNGが時刻なしの `NAVLOG_プロジェクト名.png` です。どちらも、プロジェクト名にファイル名として使えない記号や制御文字があれば `_` に置き換えます。

- **含める入力**：Route、Check Point、Planning入力、選択時点の参照データ、手動SEA。
- **含めない情報**：未確定のMAP Route Draft、Last Calculation・計算結果、気象raw cache、認証・所有者情報、内部revision・同期情報。自動SEAは取込先で再取得が必要です。

取込は新しいIDの保存済みProjectを追加し、現在の作業画面を維持します。保存済み一覧から開き、通常の確認・計算を行ってください。同名のProjectも上書きしません。ログイン中は受信側Account、未ログイン時はLocal-onlyの通常Projectとして保存します。取消・検証失敗・保存失敗でも既存データと現在の作業を保持します。

ファイルは2 MiB以下、Route node・section・Check Pointは各500件以下です。形式・対応version・必須項目・型・有限数・参照整合・重複IDを検証し、不正ファイルは理由を表示して拒否します。旧NAV LOG JSON v1（`autonavlog.navlog`）は復元に必要な入力を含まないため、取込時に理由を表示して拒否します。旧形式のダウンロード・コピーは提供しません。旧版や将来versionを推測で移行しません。

FORECASTは再計算時に利用できるWeather model / Runを通常の規則で選び、元と同じ結果を保証しません。URL共有とは別の機能で、配布済みファイルや受信側のProjectを遠隔回収することはできません。

### 3D KML エクスポート（「Google Earth」）

- 最後に正常完了した計算の Project と結果のみから導出し、保存ファイル名には計算時の Project 名（ファイル名に使えない文字は置換）を付けた `.kml` を使用します。
- **導出規則**：
  - **CLIMB**：保存された出発標高から最初の CLIMB 目標高度へ、計算済み所要時間に沿って補間します。
  - **CRUISE**：通常 Leg の高度変更は起点の変針後に **上昇 900 fpm / 降下 500 fpm** で遷移し、到達後は水平維持します（この描画レートは EOC 降下率設定とは独立であり、NAV LOG の時間・距離・燃料を変更しません）。短い Leg で到達前に次点へ着く場合は到達高度までを描画し、手前の Leg を先読み変更しません。
  - **EOCとの高度整合**：EOC前の通常高度変更が完了せず、保存されたEOC降下開始高度と矛盾する計算結果は、3D KML側で降下率や高度を変えて補正しません。計算コアでEOCを前Legへ遡らせるなどして整合したLast Calculationを生成し、共通Vertical Profileから出力します。
  - **EOC snapの描画例外**：[計算規則](calculation_rules.md#descent--eoc)に従い、snap由来と確認できる30秒以内の時間差だけは描画降下率で吸収します。保存されたNAV LOGの値は変更せず、減速60秒を維持します。snapの記録がない旧計算結果や、高度不連続をこの例外で正常に見せることはしません。
  - **DESCENT / VISUAL ARRIVAL**：保存された降下情報（水平維持・減速時間を含む）を反映し、Visual Arrival 区間は VREP 高度から計算時の目的空港標高へ距離按分で降下します。 上記snap例外を除き、DESCENT区間の所要時間が保存された垂直降下・減速時間の合計と整合しない場合は出力不可とし、超過分を水平飛行として追加しません。
  - **RJFM 帰路**：物理経路と運用時間に沿って出力し、参考案内用の西側延長経路は追加しません。
  - **地球曲面補正と形式**：RCA / EOC および Check Point 正横投影点は保存境界を使用し（地上 Check Point は高度付き経路点と分離し、付属データに時刻・高度・距離を記録）、長い直線が地球内部を貫通しないよう **1 NM 以下の間隔** で測地線サンプリングします。高度は ft MSL から m へ変換し、絶対高度・地上への延伸表示を付帯します。
- 入力変更等で計算結果が古い状態（stale）になった場合でも KML エクスポート自体は有効のまま維持し、有効な直前の正常計算結果を出力したうえで、編集した内容は含まれない旨を画面表示および出力 KML ファイルの説明欄で知らせます。一方、有効な計算結果がない初回失敗や、空港標高・降下情報など必要な描画情報が欠落している場合は 3D KML エクスポートを無効化し、再計算を求めます（計算の成功・失敗・stale に応じて、直前の正常結果に基づく表示と警告が一致します）。

### ブラウザ保存・クリップボードの操作制約

- ブラウザでのファイル保存はダウンロード開始成功をもって完了とみなします（OS の保存ダイアログ承認やディスク書込完了までは保証しません）。
- クリップボード読み書きはユーザー操作（クリック）の文脈内で直接呼び出し、事前の権限プローブを行いません。非対応・拒否・キャンセル時（Safari の貼り付け確認 UI でのキャンセルを含む）は、読み取りなら手動 KML 貼り付けダイアログ（およびファイル選択への導線）へ案内し、書き込み失敗時はコピー成功を装わず失敗を通知します。

## 外部リンク・接続状態ヒント

- 外部参照リンクは HTTP / HTTPS のみを許可し、元画面へ干渉しない独立した別タブで安全に開きます（地図の出典リンクは地図ライブラリの標準挙動を維持）。外部リンクを開いても進行中の計算状態や保留中の保存を解除・干渉しません。
- ブラウザから得られるオンライン／オフライン／不明の接続状態は最小限の参考ヒントにとどめ、サーバー疎通確認やバックグラウンド監視、Local 計算・保存の可否判定には使用しません。
