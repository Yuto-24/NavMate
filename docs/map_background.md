# MAP の背景画像

Static Web（Local 実行）では、地図上の「背景地図」切替により標準地図と衛星・空中写真を切り替えられます。選択状態は端末ローカルにのみ保持し、Project、Account Sync、Last Calculation には含めません（ブラウザ保存が拒否された場合も画面内の切替は動作します）。Legacy 画面は従来の OpenStreetMap（OSM）のみとし、画像配信元の CSP 許可を追加しません。

## 配信元と表示範囲

[地理院タイル一覧](https://maps.gsi.go.jp/development/ichiran.html) と [国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html) を 2026-11-08 に確認して採用しています。リアルタイムの Web 表示は出典明示で申請不要です。有料契約・API キー・課金 API を追加せず、[無料枠の運用条件](static_production.md#無料枠の運用条件)に従います（外部配信の可用性・無制限利用は保証しません）。

| 表示倍率 | 画像 | 欠損時 |
| --- | --- | --- |
| z0–1 | OSM | 既存地図の配信条件に従う |
| z2–13 | 全国ランドサットモザイク `lndst` | OSM |
| z14–18 | 全国最新写真 `seamlessphoto` | z13 のランドサットを拡大、その下に OSM |
| z19 | z18 の写真を拡大 | z13 のランドサットを拡大、その下に OSM |

- 画像タイルは日本全国・離島を含む **北緯 20–46°、東経 122–154°** と交差するタイルだけを要求します。国外は対応保証外であり、範囲外は OSM を表示します。画像の撮影時期・画質は地域により異なります。
- HTTP エラーのタイルは透明画像として扱い、下層を表示します（正常応答画像の画素による欠損判定は行いません）。全配信元が利用不能でも経路・地点の描画と操作は維持します。
- OSM を最下層に保持し、写真の背後にランドサットを保持します。表示範囲内の取得とブラウザ通常の HTTP キャッシュを用い、追加の事前取得・オフライン保存・独自リトライ・画像用専用 Proxy は設けません。

## 出典表示

OSM は下層として使用するため、その出典（`© OpenStreetMap contributors`）を地図上に常時表示します。画像モードでは表示倍率に応じて地理院タイル一覧へのリンクと、配信元指定の以下の表記を追加します。

- **ランドサット**：`データソース：Landsat8画像（GSI,TSIC,GEO Grid/AIST）, Landsat8画像（courtesy of the U.S. Geological Survey）, 海底地形（GEBCO）`
- **写真**：`GRUS画像（© Axelspace）`（沖ノ鳥島の対象画像を漏らさないよう写真レイヤー全体に付記）

部分欠損・障害時も一部画像が表示される可能性があるため、有効なレイヤーの出典は保持します。また、現行設計では z14 以上でも写真の取得失敗時に備え下地として `lndst` を保持するため、Landsat のクレジットも外しません。

## 表示配置

- 背景切替は地図上に配置し、追加の出典説明は三点メニュー（「その他」）内の「お知らせ」の下にある「地図の出典」に置きます。メニューは必須クレジットの代替にしません。
- [OSM tile policy](https://operations.osmfoundation.org/policies/tiles/) および地理院の[出典の記載方法](https://www.gsi.go.jp/LAW/2930-meizi.html)に従い、地図表示中に必要な出典を隠さず、狭い画面や全画面 MAP でも折り返して表示します。空域データの出典は独立して維持します。

> **参考（実タイル確認と自動検証）**：採用前の札幌・宮崎・与那国島・沖ノ鳥島（`lndst` z13 / `seamlessphoto` z14・z18 計 12 応答）の HTTP 200 確認（全国・将来の品質保証ではない）および自動検証境界は [testing.md](testing.md) を参照してください。
