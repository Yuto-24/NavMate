# MAP の背景画像

Static Web（Local実行）では「背景地図」で標準地図と衛星・空中写真を切り替えられる。
選択は端末の `autonavlog.map-background.v1` に保存し、Project、Account Sync、
Last Calculationには含めない。保存を拒否された場合も、その画面での切替は可能。
Legacy画面は既存のOSMのみとし、画像配信元のCSP許可を追加しない。

## 配信元と表示範囲

[地理院タイル一覧](https://maps.gsi.go.jp/development/ichiran.html) と
[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)
を2026-11-08に確認して採用した。リアルタイムのWeb表示は出典明示で申請不要。
有料契約・APIキー・課金APIを追加せず、[無料枠の運用条件](static_production.md#無料枠の運用条件)
に従う。外部配信の可用性・無制限利用は保証しない。

| 表示倍率 | 画像 | 欠損時 |
| --- | --- | --- |
| z0–1 | OSM | 既存地図の配信条件に従う |
| z2–13 | 全国ランドサットモザイク `lndst` | OSM |
| z14–18 | 全国最新写真 `seamlessphoto` | z13のランドサットを拡大、その下にOSM |
| z19 | z18の写真を拡大 | z13のランドサットを拡大、その下にOSM |

画像タイルは日本全国・離島を含む北緯20–46度、東経122–154度と交差するタイルだけを
要求する。国外は対応保証外で、この範囲外はOSMになる。画像の撮影時期・画質は地域で異なる。
HTTPエラーのタイルは透明画像に置き換えて下層を見せる。正常応答画像の画素による欠損判定はしない。
全配信元が利用不能でも経路・地点の描画と操作は維持するが、背景画像は保証できない。

OSMを最下層に保持し、写真の背後にランドサットを保持する。Leafletの表示範囲内の取得と
通常のブラウザHTTPキャッシュを用い、追加の事前取得・オフライン保存・独自リトライは行わない。
画像用の専用proxyやサーバーは設けない。

## 出典表示

OSMは下層として使用し、その出典を常に表示する。画像モードでは表示倍率に応じて
地理院タイル一覧へのリンクと、配信元指定の以下の表記を追加する。

- ランドサット：`データソース：Landsat8画像（GSI,TSIC,GEO Grid/AIST）, Landsat8画像（courtesy of the U.S. Geological Survey）, 海底地形（GEBCO）`
- 写真：`GRUS画像（© Axelspace）`（沖ノ鳥島の対象画像を漏らさないよう写真レイヤー全体に付記）

出典は有効なレイヤーに対応する。部分欠損・障害時も一部画像が表示される可能性があるため、
有効レイヤーの出典は保持する。既存の `MapAttributionLayout` が出典欄の高さに追従する。

## 検証の境界

採用前の実タイル確認では、札幌・宮崎・与那国島・沖ノ鳥島それぞれの中心1タイルで、
`lndst` z13と`seamlessphoto` z14/z18の計12応答がHTTP 200・画像形式だった。
全国の全タイル被覆や将来の配信品質を証明する検査ではない。

`web/e2e/map-background.spec.ts` は制御したタイル応答で、切替・再起動・新規Projectでの
選択保持、経路・表示位置・空域、1100/1440pxの領域順序、欠損・配信障害、
ズーム境界、国外、端末保存拒否を検証する。
既存FTD Goldenの1100pxケースでは、背景切替がNAV LOGの表示値と計算回数を変えないことを検証する。
