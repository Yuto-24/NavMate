# 出発位置の VOR Tracking Mode

VOR Tracking Mode は、登録済み 14 空港の出発位置を対応する VOR の座標へ切り替え、第 1 Physical Leg の磁気基準を出発 VOR の公示偏差へ揃える仕様です。地図上で VOR を手動選択する必要はなく、到着位置や NAV LOG の VOR/DME 列の選局とは独立して動作します。

## 変更するもの・保持するもの

- **変更するもの**：先頭経路点の座標・表示名・出典、および第 1 Physical Leg の VAR・MC・MH の磁気基準（MAP 作成と KML 取込の両方に適用）。
- **保持するもの**：出発空港 ID、空港標高、離陸・上昇条件、到着点と到着処理。
- 通常の開始位置検証（0.5 NM）は通常時は空港基準点、VOR Tracking Mode 時は採用した VOR 座標と比較します。さらに VOR Tracking Mode の計算実行時には、第 1 Physical Leg の始点が採用した VOR 座標と一致している必要があります（数値許容差 `1e-6 NM`、超過時は計算を拒否）。
- モード変更や計算条件変更の後は再計算が必要です。

## 対応局と根拠

- 14 空港それぞれの対応局と転記値・出典は [転記値と出典記録](evidence/airport-vor-departure.json) を正本として管理します。近接距離から対応局を推定しません（鹿児島は `KGE`、岡山は `OYE`、高松は `KTE` の VOR 座標を用い、`KTE` の DME 座標は VOR 座標と異なるため用いません）。
- 根拠となる AIP AD 2.19 の 14 原本情報および個別局の採用記録（`OYE` 等）は [データ来歴（VOR/DME 基準局）](data_provenance.md#nav-logのvordme基準局) を参照してください（PDF 原本や非公開の保管先 ID はリポジトリへ含めません）。
- 本機能はライブ NOTAM、局の供用状態、または実電波の受信可能性を確認するものではありません。

## 保存と互換性

- Project に設定された出発 VOR の採用局情報（局 ID・座標・出典）はそのまま保持します。
- この機能導入前の旧計画（VOR モード記録を持たない保存済み Project や作業中セッション）は、従来どおり通常モード（空港基準出発）として読み込み、未完の入力を保持します。
- 再読み込みや他の計画入力の更新では採用済みの局情報を維持します。通常モードへ戻して再度 VOR Tracking Mode を選んだ場合は、その時点の対応表を採用します。

## 第1 Legの磁気基準

- 第 1 Physical Leg の全計算区間（Calculation Zone）は、出発局の公示 Declination を西正の VAR として採用します。TC と WCA は従来の WGS84 経路・風計算を維持します（詳細は [計算規則](calculation_rules.md)）。任意の VOR/DME 列の選局は影響しません。
- 公示偏差と出典は単一の VOR 局データ原本（[データ来歴](data_provenance.md#nav-logのvordme基準局)）から供給し、Web 表示と計算コアで共用します。座標の出典と偏差の出典で改訂日が異なる場合があるため、それぞれ独立した出典を保持します。
- 出発専用局（`OYE` 等）は出発 VOR Tracking 専用として管理し、NAV LOG の VOR/DME 選局一覧には含めません。偏差は公示値（例：`OYE` は 8°W）をそのまま採用し、年変化は加算しません。
- 保存済み Project の局 ID・座標を対応表と照合して偏差を解決します。未知の局・座標や偏差欠落がある場合は第 1 Leg の MC/MH を正常値として出力せず、計算をブロックします。
- 計算条件（採用局・偏差規則・値・出典）が変わった場合は、VOR モード適用中の旧計算を再計算対象として扱います（通常モードの従来計算には影響しません）。
