# 区間別SEA

NAV LOGのTOとPAの間にあるSEA列は、C'k Pointで区切った各区間の値を、その終点の行に表示します。
RCA/EOCの途中行ではSEA区間を分割せず、別表は設けません。
最終進入で計算の子行を省略する場合も、C'k Pointで区切った区間のSEAは本表内の終点行に表示します。
風・ETE・燃料の計算、高度の自動変更、低高度の承認には影響しません。
高度入力欄との連携と承認は #315 の対象です。

画面ではSEA列の値・手動入力、必要な警告、地形の再取得、国土地理院の出典を扱います。
地形点KMLの取込・解除、資料名や照合根拠の入力、確認チェックは設けません。
区間別の画素数・取得日時・内容ハッシュなどの診断情報も画面には表示しません。

## 評価範囲と算式

- Physical Legの始点、経路上へ投影したC'k Point、終点で区間を分けます。
  同じLeg内の複数区間も独立して評価します。RCA/EOCではSEA区間を分割しません。
- 経路の左右3 NMと、終点の進行方向側の半径3 NMを含めます。
  始点では進行方向と直角に区切り、後方を含めません。
  この端点条件は #314 の実施時に利用者が指定した条件です。
- 完全に取得できた国土地理院DEM10Bの領域最高値を使用します。
  既存Projectに有効な地形点KMLが保存されている場合は、その領域内最高値と比較して高い方を採用します。
- SEAは最高標高をftへ換算し、100 ft単位で切り上げて1,000 ftを加えた値です。
  ちょうど100 ft単位の値をさらに切り上げることはありません。

## 未確定と手動値

DEMの未取得、欠損、不正、評価範囲の未対応がある場合はSEA列を「未確定」とし、
警告を表示します。部分的な最高標高やKMLの点情報で欠損領域を補いません。
NAVLOGの他の計算は継続します。

SEA列で手動値を入力すると、その値を優先して表示・保存します。
空欄にすると自動値へ戻ります。比較できる自動値を下回る場合は警告します。
自動値が未確定のときも手動値を入力でき、未確定警告は解除しますが、
自動値との照合を実施したとは扱いません。

通常の再計算、気象・高度・名称の変更、保存・再読込では手動値を保持します。
区間の経路形状、C'k Pointの投影位置による区切り、評価範囲が変わった区間では
手動値を解除します。一度解除した値は、元の形状に戻しても自動復活しません。

## 取得と保存

NAVLOG表示時に、未評価の区間の地形取得を開始します。
利用者は「地形を再取得」で再評価できます。地形取得中も他の航法計算は利用できます。
計算後に経路やProjectを切り替えた場合、古い取得結果を新しい評価対象へ適用しません。

取得した最高値、被覆判定、必要・有効・欠損・未取得・不正の画素数、
出典・取得日時・内容ハッシュ、既存のKML地形点、手動値をProjectへ保存します。
PNG標高タイル自体の永続保存は行いません。
保存済みの自動値は保存時点の評価であり、現在の地形データの再取得を保証しません。
既存のProjectやLast CalculationにSEAがない場合は未確定から開始します。

SEAには専用の保存ボタンはなく、入力欄からフォーカスが外れた時に自動保存されます。
古い経路情報などにより更新自体が拒否された場合、受理されなかった新しい値は保存された値ではなく、
入力欄は従前の値へ戻されます。現在の経路と内容を確認し、必要に応じて再入力してください。

Localで更新が受理された後に端末への保存に失敗した場合は、現在の作業状態に変更が残ることが
ありますが、永続保存は保証されません。画面の通知に従って保存をやり直し、保存状態を確認してください。
再読込時の結果は失敗の種別、作業状態の復元、端末の保存状態によって異なり、失敗した値が
保持されるか消失するかは一律ではありません。再読込前に保存状態を確認し、再読込後は表示値を確認してください。

既存Projectの地形点KMLと確認済みの出典は保持し、従来の採用条件でSEA計算に使用します。
画面の取込欄を廃止しても、保存済みの地形点やSEA値は削除しません。
経路用KMLのImportは別の機能として継続します。
保存済み地形点の採用条件と障害物の除外は[地形入力の契約](terrain_inputs.md)に従います。

## 診断情報の保持と再利用

画面から外した診断情報は、SEAが未確定になった理由や使用データを後から調べるために保持します。

| 保持する情報 | 調査での用途 |
| --- | --- |
| 被覆判定と画素数 | 欠損、通信等による未取得、形式不正を区別する |
| タイルの取得元URL・取得日時・内容ハッシュ・出典・標高基準 | 使用したデータを識別し、再取得したデータとの差を照合する |
| 区間ごとの地形最高値、それから求める自動SEA、手動SEA | 同じ評価区間で、表示値がどの入力から得られたかを調べる |

画素数は検査した部分領域の集計値です。未検査領域を含まず、区間全体の一意な画素数とは限りません。
保存内容はその時点の評価であり、再取得で更新されます。原タイルや取得失敗の詳細ログは保存しないため、
ハッシュだけで過去の取得処理を再現できるものではありません。

将来の不具合報告機能では、対象区間の状態とこの診断情報を抽出して利用できます。
現在は専用の報告・送信機能はなく、診断情報の保持によって外部送信が始まることもありません。
保存場所と既存JSON出力からの確認方法は[SEA診断情報の確認](testing.md#sea診断情報の確認と再利用)を参照してください。

## 出典と限界

[国土地理院DEM10B](https://cyberjapandata.gsi.go.jp/development/ichiran.html)は
平滑化された標高値です。全画素を取得しても、実地形の絶対最高点を保証しません。
人工障害物は含みません。離島の鉛直基準、測量・改定時点、KMLの解釈と照合の
制約は[地形入力の仕様](terrain_inputs.md)を参照してください。

地形領域はWGS84の経路に沿って構成し、DEM画素の閉じた範囲が境界に触れる場合も
含める保守的な評価です。曲線を多角形へ近似する際の小さな外側余裕も含むため、
数学的に厳密な3 NM内の点最高値と完全に一致するとは限りません。
KML点の採否は3 NMの測地距離と始点の前後で判定します。

現行の自動評価は緯度の絶対値50度以下、1区間250 NM以下に限定し、日付変更線越え、
領域上限超過、時間内に取得できない範囲は未確定にします。
この制約によって範囲を切り捨てて確定値を出すことはありません。
SEA表示は安全性や飛行可否の保証ではなく、実運航前の原資料との最終照合が必要です。
