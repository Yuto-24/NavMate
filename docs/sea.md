# 区間別SEA

NAV LOGのTOとPAの間にあるSEA列は、C'k PointとPhysical Legの端点で区切った区間の自動SEAを、その終点の行に表示します。
表示するのは、計算で確定した巡航部分（RCA〜EOC）と正の長さで重なる区間だけです。
巡航外の区間、計算未成立、巡航部分が存在しない場合は空欄とし、PNGも同じ扱いにします。
RCA/EOCではSEA区間も地形の評価範囲も分割しません。上昇・降下と巡航が混在する区間には区間全域のSEAを使います。
SEAは自動算出した参考値のみを表示し、アプリ内での手入力・上書きはできません。
計画高度、風・ETE・燃料の計算、保存済み計算結果を自動変更しません。

画面ではSEA列の自動値、必要な警告、地形の再取得、国土地理院の出典を扱います。
地形点KMLの取込・解除、資料名や照合根拠の入力、確認チェックは設けません。
区間別の画素数・取得日時・内容ハッシュなどの診断情報も画面には表示しません。

## 評価範囲と算式

- Physical Legの始点、経路上へ投影したC'k Point、終点で区間を分けます。
  各区間を独立して集約し、共通する地形の評価結果は再利用します。
- Physical Legの左右3 NMを含め、出発点・到着点・投影したC'k Pointでは進行方向に直角な境界で区切ります。前後への延長は設けません。
- 変針点では外側に半径3 NM・中心角が変針角の扇形を追加し、接続する前後のSEA区間の双方に含めます。
  直進時は扇形を追加しません。変針点の内側など領域内部の重複は許容します。
- 国土地理院DEM10Bを区間の全評価範囲で調べ、有効な標高の最高値を使用します。
  欠損を見つけても評価を打ち切らず、残りの範囲を調べます。
  既存Projectに有効な地形点KMLが保存されている場合は、その領域内最高値と比較して高い方を採用します。
- SEAは最高標高をftへ換算し、100 ft単位で切り上げて1,000 ftを加えた値です。
  ちょうど100 ft単位の値をさらに切り上げることはありません。

## 未確定とCaution

数値・参考値・取得中・未確定警告・低高度Cautionはいずれも巡航と正の長さで重なる区間だけが対象です。
巡航境界に接するだけの区間や、上昇・降下のみの区間には表示しません。

完全被覆の場合は数値のみ、欠損だけを含み有効なDEM標高がある場合は数値に `*` を付けて表示します。
`*` は欠損を含む参考値で、実際のSEAが表示値より高い可能性を示します。
該当値がある場合はNAV LOG欄外に一度だけ意味を記載し、PNGにも同じ数値・記号・注記を出力します。

有効なDEM標高が一切ない場合、未取得・通信失敗、不正、未対応の評価範囲、処理中断がある場合は
SEA列を「未確定」とし、警告を表示します。途中までの最高値やKMLの点情報で欠損領域を補いません。
NAV LOGの他の計算は継続します。

計画巡航高度が自動SEA（`*` 付きの参考値を含む）の数値を下回る場合はCautionを表示します。
算出単位はC'k Point間のまま、計算後に確定したRCA〜EOCの巡航部分と
長さをもって重なる区間だけを比較します。上昇・降下部分、境界に接するだけの区間は対象外です。
同じ高度の場合や自動SEAが未確定の場合は低高度Cautionを表示しません。
計画高度が表示値以上でCautionがなくても、安全性を確認できたことにはなりません。

入力変更時は古いCautionを解除し、再計算後に新しい巡航範囲で再評価します。
初回計算前や計算が成立しない場合には巡航範囲を仮定したCautionを表示しません。
地形の再取得で自動SEAが変わった場合も再評価します。
Cautionによる承認操作や入力確定・計算の停止は行いません。

旧Projectの手動SEAは互換性・診断情報として保持しますが、表示・比較には使いません。
区間形状やC'k Pointの位置が変わった場合は該当区間を再集約します。

## 取得と保存

経路確定直後および保存済みProjectの再開時に、未評価範囲の地形評価を開始します。
NAV LOGの計算前でも全経路を評価し、完了した区間から順次反映・自動保存します。評価中も入力・保存・計算を止めません。
C'k Pointの追加・移動・削除時は共通する評価結果を再利用し、正確な境界の変更部分を再評価します。
変針点の変更時は、影響するPhysical Leg・扇形・隣接区間を再評価します。
計画高度・ETD・気象・降下率の変更やNAV LOGの再計算だけでは地形を再取得しません。
利用者が「地形を再取得」を実行した場合は全経路を再評価します。

巡航対象の評価待ち区間だけにスピナーと「取得中」を表示し、完了した区間から数値・欠損参考値・「未確定」に切り替えます。
待機中は「未確定」警告を出しません。再取得中も既存の評価値は保持します。
通信失敗時は取得済み領域の結果を保持し、未取得タイルを1回の取得処理につき最大3回まで試行します。
評価済みのDEM欠損は再試行の理由にしません。
再試行後も取得できない場合や60秒の取得上限に達した場合はスピナーを消し、評価できなかった区間を未確定にします。
処理中の表示は一時的なUI状態であり、ProjectやJSONには保存しません。PNGは評価済みの値を使います。
経路やProjectを切り替えた場合、古い取得結果を新しい評価対象へ適用しません。

差分再利用に用いる中間評価結果は端末内に上限8 MiBで保存し、ProjectやAccount Syncには含めません。
保存拒否や容量不足の場合はセッション内の有限キャッシュで継続します。消失した中間結果は再生成できます。

取得した最高値、被覆判定、全範囲の評価済み状態、必要・有効・欠損・未取得・不正の画素数、
出典・取得日時・内容ハッシュ、既存のKML地形点、旧手動値をProjectへ保存します。
PNG標高タイル自体の永続保存は行いません。
保存済みの自動値は保存時点の評価であり、現在の地形データの再取得を保証しません。
既存のProjectやLast Calculationに新方式のSEAがない場合は未評価から開始します。
従来の前方半円方式で保存した値は新方式では使用せず再評価し、旧診断履歴は保持します。
旧版で不完全被覆として保存した最高値は途中までの値のため、再取得まで未確定を維持します。
Projectには数値と参考値の区別を保持します。Project JSONは入力交換用で、計算したSEAや診断情報は含めません。

地形の取得結果は自動保存します。更新が拒否された場合は現在の経路を確認し、
「地形を再取得」で再試行してください。
端末への保存に失敗した場合は現在の作業状態に変更が残ることがありますが、永続保存は保証されません。
通知に従って端末の空き容量やブラウザーの保存設定を確認し、ヘッダーの「保存」で再試行してください。
再読込前に保存状態を確認し、再読込後は表示値を確認してください。

既存Projectの地形点KMLと確認済みの出典は保持し、従来の採用条件でSEA計算に使用します。
画面の取込欄を廃止しても、保存済みの地形点やSEA値は削除しません。
経路用KMLのImportは別の機能として継続します。
保存済み地形点の採用条件と障害物の除外は[地形入力の契約](terrain_inputs.md)に従います。

## 診断情報の保持と再利用

画面から外した診断情報は、SEAが未確定になった理由や使用データを後から調べるために保持します。

| 保持する情報 | 調査での用途 |
| --- | --- |
| 被覆判定、全範囲の評価済み状態と画素数 | 欠損、通信等による未取得、形式不正を区別する |
| タイルの取得元URL・取得日時・内容ハッシュ・出典・標高基準 | 使用したデータを識別し、再取得したデータとの差を照合する |
| 区間ごとの地形最高値、それから求める自動SEA、手動SEA | 同じ評価区間で、表示値がどの入力から得られたかを調べる |

画素数は評価対象として特定できた領域の集計値で、取得できなかった画素と領域間の重複を含みます。
中断時にまだ評価対象を特定していない領域は含まず、全範囲を評価済みの値と区別します。
保存内容はその時点の評価であり、再取得で更新されます。原タイルや取得失敗の詳細ログは保存しないため、
ハッシュだけで過去の取得処理を再現できるものではありません。

将来の不具合報告機能では、対象区間の状態とこの診断情報を抽出して利用できます。
現在は専用の報告・送信機能はなく、診断情報の保持によって外部送信が始まることもありません。
保存場所と既存JSON出力からの確認方法は[SEA診断情報の確認](testing.md#sea診断情報の確認と再利用)を参照してください。

## 出典と限界

[国土地理院DEM10B](https://cyberjapandata.gsi.go.jp/development/ichiran.html)は
平滑化された標高値です。全画素を取得しても、実地形の絶対最高点を保証しません。
人工障害物は含みません。離島の鉛直基準、測量・改定時点、KMLの解釈と照合の
制約は[地形入力の仕様](terrain_inputs.md)を参照してください。

地形領域はWGS84の経路に沿って構成し、DEM画素の閉じた範囲が境界に触れる場合も
含める保守的な評価です。曲線を多角形へ近似する際の小さな外側余裕も含むため、
数学的に厳密な3 NM内の点最高値と完全に一致するとは限りません。
KML点の採否も左右3 NM・直角境界・変針点外側の扇形という同じ測地条件で判定します。

現行の自動評価は緯度の絶対値50度以下、1区間250 NM以下に限定し、日付変更線越え、
領域上限超過、時間内に取得できない範囲は未確定にします。
この制約によって範囲を切り捨てて確定値を出すことはありません。
SEA表示は安全性や飛行可否の保証ではなく、実運航前の原資料との最終照合が必要です。
